## Blocking amendments (exact)

R1. Restore the retained normative content: embed the §3.1 field/collection bounds table (or a complete equivalent within A7) covering sectionCount, items, item.rarity/ilvl/socketCount/socketRunes/enhancementCount/category/tier/tags/registryId/baseFormId, hunt/materials/packs/strings, containers/quests/overrides/skills, rank/stage/xp/difficulty/curve/endgame, record-size, trailing/duplicate/unknown; embed the §3.3 budget arithmetic table or explicitly cite it by path+SHA as a retained normative artifact. Fix A6's dangling "§3.1 table below" reference. Alternatively, since the merged rev7 must be self-contained, restate sections 3.1-3.4 fully rather than claiming retention.

R2. Freeze the seam: "static LoadRecords(std::vector<Record>, CoSaveState& out)" must become a single named signature that carries the per-record version, e.g. "static bool LoadRecords(const std::vector<Record>&, std::uint16_t recordVersion, CodecState& out)" with Record defined (type/size/payload) in the pure header; state the exact zero/one/multi/unknown/malformed-then-valid expectations against that signature. Resolve the A1(b) vs A6 class-10 contradiction: unknown records must be drained/bounded and the stream must continue to a later valid record (rev6 §3.4 behavior), not collapse the whole stream to defaults.

R3. Make the host split compilable: state explicitly that CoSaveState (and the PODs it needs: ItemMetadata/Enhancement/LadderOverride) move to CoSaveCodec.h with no PCH/Core.h/RE/SKSE includes; CoSave.h keeps a type alias/adapter and codec types do not pull Core.h; A1 seam and host tests use the codec types. A1(b) registry post-state stays F11-only. Add a compile-only gate that the pure pair has no forbidden include (grep check).

R4. Rewrite A6 into two tables: (a) rejection classes with one exact token each and required crafted payload/expected decode=false; (b) accepted/normalized classes (unknown-record bounded drain, dedupe, exact-boundary accept) with expected decode=true and no token. Add a class->token mapping table and remove placeholders ("<collection>-count", "string.*", "reject item.*") by listing the concrete token per class; for class 1, split into four sub-classes with one token each.
